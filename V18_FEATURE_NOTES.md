# MiniWiki v18 Feature Notes

- Corrected wiki image behavior: `[[Image:name]]` / `[[File:name]]` embeds an uploaded image inline; `[[name]]` links to an uploaded file/image when one exists.
- Search results now show a red create-page link for missing searched titles.
- User list now links to `User:Name` and `User talk:Name` pages.
- Added an `/admin` dashboard that centralizes user, block, password, permissions, CheckUser, deleted page, and upload/image moderation links.
